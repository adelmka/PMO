# User Guide

1. In **New request**, enter customer organization and request details, classifications and systems; submit and record the generated reference.
2. In **Projects**, open the record to set review outcome, assignments, phase/status, IT Demand, estimates, links and a note.
3. Use **Configuration** to add a category, type, construction agency or impacted system. New values are available immediately at intake.
4. On **Dashboard**, switch Month/Quarter/Year to compare received and completed work and inspect portfolio status.

For the pilot, upload DSD/DDSD/UAT documents to the approved enterprise repository and paste secure links. Do not put sensitive documents in free-text notes.
